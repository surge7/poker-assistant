# Резервные копии иконки для маркета (512×512)

- **icon_launcher_foreground_512_a_chip.png** — фишка с буквой **A** (основная иконка приложения).
- **icon_launcher_foreground_512_current.png** — предыдущая версия (если есть).

Мастер-файл для сборки: `android/app/src/main/res/icon_launcher_foreground_512.png`.

Перегенерация mipmap из мастера:

```bash
npm run generate-icon
```
