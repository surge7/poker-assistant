# VK Cloud и Yandex Cloud: статический сайт при минимальном трафике и размере

Для маленького SPA и небольшого трафика оба облака укладываются в копейки или в бесплатный лимит.

---

## Размер этого приложения (минимум)

После `npm run build` папка **dist** занимает примерно **52 КБ**:

- `index.html` — несколько КБ  
- `assets/index-*.js` — ~32 КБ  
- `assets/index-*.css` — ~16 КБ  

Один визит (загрузка страницы + JS + CSS) ≈ 1–3 запроса GET и ~52 КБ трафика. При **1000 посещений в месяц**: ~1000–3000 GET и **~50 МБ** исходящего трафика — оба облака при «минимуме» укладываются в бесплатный лимит (Yandex) или в рубли (VK Cloud).

---

## Сравнение при «минимуме»

| Параметр | Yandex Cloud Object Storage | VK Cloud Object Storage (Hotbox) |
|----------|-----------------------------|-----------------------------------|
| **Бесплатно в месяц** | 1 ГБ хранения, 10 000 PUT/LIST, 100 000 GET, **100 ГБ исходящего трафика** | Нет фиксированного free tier |
| **Бонус для новых** | Нет отдельного бонуса для Object Storage | **5 000 ₽** (физлица) или **12 000 ₽** (юрлица) на **60 дней** — при минимуме хватает надолго |
| **Хранение** | После 1 ГБ — ~2,21 ₽/ГБ в месяц | 2,28 ₽/ГБ в месяц |
| **Исходящий трафик** | После 100 ГБ — ~1,68 ₽/ГБ | 1,31 ₽/ГБ |
| **Входящий трафик** | Не тарифицируется | Не тарифицируется |
| **Оценка для ~52 КБ сайта, 500–2000 посещений/мес** | **0 ₽** (укладывается в free tier) | **0 ₽** (бонус) или **≈ 0–2 ₽/мес** (трафик &lt; 1 ГБ) |

**Итог:** при маленьком размере и трафике **Yandex Cloud** даёт **0 ₽/мес**; **VK Cloud** — можно уложиться в приветственный бонус или платить **1–5 ₽/мес**.

## Yandex Cloud Object Storage (оптимально для минимума)

### Бесплатно каждый месяц

- **1 ГБ** хранения (стандартный класс).
- **10 000** операций PUT, POST, PATCH, LIST.
- **100 000** операций GET, HEAD, OPTIONS.
- **100 ГБ** исходящего трафика.

Для статического сайта **~52 КБ** (как у этого приложения) и сотен/нескольких тысяч просмотров в месяц этого более чем хватает — плата **0 ₽**. Официальные лимиты: [тарификация Object Storage](https://yandex.cloud/ru/docs/storage/pricing).

### Пошагово: развернуть статику в Yandex Cloud

1. **Регистрация**
   - Зайти на [console.yandex.cloud](https://console.yandex.cloud).
   - Войти по Яндексу или зарегистрироваться.
   - При первом входе создать биллинг-аккаунт (привязка карты, списаний не будет, пока не выйдете за free tier).

2. **Создать бакет**
   - В консоли: **Object Storage** → **Создать бакет**.
   - Имя бакета — уникальное (например `poker-trainer-static`).
   - Класс хранения: **Стандартное**.
   - Доступ: **Публичный на чтение** (чтобы файлы отдавались по ссылкам).
   - Создать бакет.

3. **Включить хостинг статического сайта**
   - Открыть бакет → **Настройки** (или раздел про статический сайт).
   - Включить **Хостинг статического сайта**.
   - Главная страница: `index.html`, страница ошибки (опционально): `index.html` (для SPA).

4. **Загрузить файлы из dist**
   - Собрать проект: `cd apps/app && npm run build`.
   - В бакете нажать **Загрузить объекты** и загрузить **всё содержимое** папки `apps/app/dist/`: файл `index.html` и папку `assets/` (со всеми файлами внутри).
   - Имена и структура должны совпадать с локальной папкой (корень сайта = корень бакета).

5. **Открыть сайт**
   - URL будет вида: `https://storage.yandexcloud.net/ИМЯ_БАКЕТА/index.html`  
     или (если настроен «сайт»): `https://ИМЯ_БАКЕТА.website.yandexcloud.net`.
   - В документации Yandex Cloud проверьте актуальный формат URL статического сайта для бакета.

6. **Свой домен (по желанию)**
   - В настройках бакета или через Certificate Manager можно привязать свой домен и HTTPS (см. документацию Yandex Cloud).

### Оценка стоимости при минимуме (для этого приложения)

- Размер сайта: **52 КБ** → **&lt; 1 ГБ** → бесплатно.
- Запросы GET: даже **10 000–50 000 визитов/мес** (по 1–3 GET на визит) → **&lt; 100 000** → бесплатно.
- Трафик: 50 КБ × 10 000 ≈ 500 МБ/мес → **&lt; 100 ГБ** → бесплатно.  
**Итого: 0 ₽/мес** при типичном маленьком трафике.

## VK Cloud Object Storage (минимум — платно, но дёшево)

### Бесплатного тарифа нет, но есть приветственный бонус

- **Физлица:** [5 000 ₽ на 60 дней](https://cloud.vk.com/bonus) после регистрации и подтверждения.
- **Юрлица** (корпоративный домен + документы): **12 000 ₽ на 60 дней**.
- Бонус можно тратить на Object Storage (не на CDN и маркетплейс). При размере сайта **52 КБ** и трафике **1–2 ГБ/мес** бонуса хватит на многие месяцы по факту расхода.

Тарификация по факту (прайс на [cloud.vk.com/pricelist](https://cloud.vk.com/pricelist), [тарификация S3](https://cloud.vk.com/docs/ru/storage/s3/tariffication)):

- **Хранение (Hotbox):** 2,28 ₽/ГБ в месяц.
- **Исходящий трафик:** 1,31 ₽/ГБ.
- Входящий трафик и API не тарифицируются.

### Оценка при минимуме (для этого приложения)

- Сайт **~52 КБ** (0,00005 ГБ): хранение **0 ₽** (округляется).
- **0,5 ГБ** исходящего трафика в месяц: 0,5 × 1,31 ≈ **0,66 ₽**.
- **1 ГБ** трафика: **≈ 1,31 ₽/мес**.

То есть при маленьком трафике — **порядка 0–2 ₽ в месяц**; с бонусом первые месяцы — **0 ₽**.

### Важно: для «сайта» нужен свой домен

В VK Cloud статический сайт отдаётся **только по привязанному домену**. Без домена доступны лишь прямые ссылки на объекты (например на `index.html`), а не адрес вида «сайт.зона». URL после привязки: `http(s)://ИМЯ_БАКЕТА.ПОДДОМЕН.ДОМЕН` — см. [хостинг статических сайтов в S3](https://cloud.vk.com/docs/storage/s3/how-to-guides/s3-domain). Если своего домена нет, можно взять недорогой (например .ru) или использовать только Yandex Cloud, где сайт доступен по `*.website.yandexcloud.net` без своего домена.

### Пошагово: развернуть статику в VK Cloud

1. **Регистрация**
   - [cloud.vk.com](https://cloud.vk.com) → регистрация/вход.
   - Создать проект. При первом входе можно получить приветственный бонус (физлица — 5 000 ₽ на 60 дней).
   - При необходимости пополнить баланс (для минимума достаточно нескольких десятков рублей после бонуса).

2. **Object Storage (S3)**
   - В проекте: **Object Storage** → создать бакет (S3-совместимый).
   - Имя — уникальное, регион — любой.
   - Доступ: публичное чтение объектов (чтобы файлы отдавались по ссылкам).

3. **Привязать домен**
   - В бакете: вкладка **Привязать домен**.
   - Нужен зарегистрированный домен и поддомен для этого бакета (например `app.ваш-домен.ru`).
   - В DNS у регистратора создать CNAME: поддомен → значение, которое укажет VK Cloud в панели.

4. **Загрузить файлы**
   - Собрать: `cd apps/app && npm run build`.
   - Загрузить в бакет **всё содержимое** папки `apps/app/dist/`: `index.html` и папка `assets/` (сохраняя структуру).
   - Через веб-интерфейс VK Cloud: загрузка объектов в бакет. Либо через S3-совместимый CLI (`aws s3 sync dist/ s3://ИМЯ_БАКЕТА/`) — ключи и endpoint взять в настройках проекта.

5. **SSL (HTTPS)**
   - По умолчанию доступ по HTTP. Для HTTPS: [обратиться в поддержку VK Cloud](https://cloud.vk.com/docs/ru/contacts), указать проект, бакет и предоставить SSL-сертификат для установки.

### Итого по VK Cloud

- **Бесплатного тарифа нет**, но приветственный бонус (5 000 ₽ / 60 дней) при минимальном трафике покрывает расходы надолго.
- При оплате по факту: размер **52 КБ** и трафик **1–2 ГБ/мес** — **порядка 0–2 ₽/мес**.
- Точный расчёт: [калькулятор VK Cloud](https://cloud.vk.com/pricing/).

## Что выбрать при «всё минимум»

- **Нужно бесплатно и без своего домена** → **Yandex Cloud Object Storage**: сайт доступен по `*.website.yandexcloud.net`. При размере **52 КБ** и небольшом трафике уложитесь в 1 ГБ, 100 К GET и 100 ГБ трафика — **0 ₽/мес**.
- **Нужен VK Cloud** → **VK Cloud Object Storage**: потребуется **свой домен** для «красивого» URL; при малом трафике — **0 ₽** (бонус 5 000 ₽ на 60 дней) или **0–2 ₽/мес**.

Оба варианта подходят для раздачи статики из папки **dist** (одна страница, скрипты и стили). Точные пункты меню и актуальные тарифы смотрите в документации: [Yandex Cloud Object Storage](https://yandex.cloud/ru/docs/storage/), [VK Cloud Object Storage](https://cloud.vk.com/docs/ru/storage/s3/).

## Опционально: кэширование (Cache-Control)

Чтобы браузеры реже повторно запрашивали одни и те же файлы, при загрузке объектов можно задать заголовок **Cache-Control** (в настройках объекта в консоли или через S3 API):

- Для **index.html**: `Cache-Control: no-cache` или короткий `max-age=60` (чтобы обновления подхватывались быстрее).
- Для **assets/*.js** и **assets/*.css** (имена с хешем): `Cache-Control: public, max-age=31536000` (год) — при следующем билде имена файлов изменятся, пользователи получат новую версию.

Это не меняет тарификацию облака, но снижает число GET-запросов и трафик при повторных визитах.
