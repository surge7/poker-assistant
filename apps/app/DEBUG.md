# Отладка приложения (в том числе UI) в Cursor

Приложение — это веб (HTML/CSS/TS), поэтому UI и логику удобнее всего отлаживать в браузере. В Cursor вы правите код, в браузере смотрите результат и DevTools.

---

## 1. Отладка UI и логики в Cursor + браузер

### Шаг 1. Запустить приложение

В терминале (в Cursor: **Terminal → New Terminal**):

```bash
cd ~/Projects/poker-assistant/apps/app
npm run dev
```

Откроется локальный сервер, обычно: **http://localhost:5173**

### Шаг 2. Открыть в браузере

Откройте в Chrome (или другом браузере): **http://localhost:5173**

- Меняете код в Cursor → Vite перезагружает страницу (hot reload) — изменения видны сразу.
- Для UI: правый клик по элементу → **Inspect** (или F12) — DevTools: вкладки **Elements** (разметка/CSS), **Console** (логи, ошибки), **Network** (запросы).

### Шаг 3. Брейкпоинты в Cursor (отладка кода)

1. В Cursor откройте нужный файл (например `apps/app/src/app.ts`).
2. Поставьте точку останова: клик слева от номера строки (появится красная точка).
3. В Cursor: **Run and Debug** (иконка слева или Ctrl+Shift+D).
4. В списке выберите **«Открыть приложение в Chrome (с отладкой)»**.
5. Нажмите **Run** (F5).

Откроется Chrome на http://localhost:5173; при срабатывании брейкпоинта выполнение остановится, переменные и стек вызовов будут видны в Cursor.

**Важно:** перед запуском отладки в Cursor обязательно должен быть запущен `npm run dev` в терминале (шаг 1).

Если при `npm run dev` в терминале Cursor появляется ошибка `EPERM` или порт не открывается — запустите dev-сервер в **системном терминале** (Terminal.app, iTerm): там те же команды, сервер поднимется на http://localhost:5173, отладку в Cursor и браузере делаете как обычно.

## 2. Отладка UI: что смотреть в браузере

- **Elements** — разметка и стили, можно менять CSS и сразу смотреть результат.
- **Console** — `console.log()`, ошибки.
- **Mobile view** (иконка «телефон/планшет» в DevTools) — проверка вида на маленьком экране (как на Android).

В коде можно добавлять `console.log(...)` и смотреть вывод во вкладке Console.

---

## 3. Отладка на Android (Capacitor)

UI в приложении на телефоне — тот же веб (WebView). Поэтому:

- Изменения в `apps/app/src/` и в `packages/core` влияют и на веб, и на Android.
- Сначала отлаживаете в браузере (п. 1–2), потом собираете APK и смотрите на устройстве.

Если нужно смотреть логи или отлаживать WebView на телефоне:

1. Подключите телефон по USB, включите **Отладка по USB**.
2. В Chrome на компьютере откройте **chrome://inspect**.
3. В списке устройств найдите ваше приложение (Покерный тренажер СР) и нажмите **inspect** — откроется DevTools для WebView (те же Elements, Console, что и для веба).

## Кратко

| Задача              | Где делать                          |
|---------------------|-------------------------------------|
| Менять разметку/CSS  | Cursor (код) + браузер DevTools     |
| Смотреть логи       | Браузер → Console                   |
| Брейкпоинты в коде   | Cursor: брейкпоинты + Run → Chrome  |
| Вид как на телефоне | DevTools → переключить на mobile    |
| Логи на Android     | chrome://inspect → inspect приложения |

Да, отладку (в том числе UI) можно делать в Cursor: код и брейкпоинты — в Cursor, просмотр и инспект UI — в браузере (и при необходимости в chrome://inspect для Android).
