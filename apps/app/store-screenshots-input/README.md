# Скриншоты для стора (RuStore и др.)

Положите сюда **исходные скриншоты** приложения (с телефона или эмулятора) в формате PNG или JPG.

Затем из папки `apps/app` выполните:

```bash
npm install
npm run store-screenshots
```

Скрипт сделает из них изображения **1080×1920 px, 9:16, JPG** — как в инструкции стора («Рекомендуем: JPG, 1080×1920 px»). Результат появится в папке **store-screenshots/** — **именно эти файлы** загружайте в консоль разработчика.

**Важно:** загружайте в стор только файлы из **store-screenshots/** (уже 1080×1920, 9:16). Исходные скриншоты с телефона чаще всего не 9:16 — стор их обрежет, и модерация отклонит.
